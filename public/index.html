입력 출처 및 게임 내 측정

  1. 무한 자원 설정을 끄고 전투 화면에서 최대 MP와 시작 MP를 기록하세요.
  2. 마나를 일부 소모한 뒤 아무 스킬도 쓰지 않고 연속 회복의 시각과 1회량을 기록하세요. 음식이나 서포터 효과는 한 가지씩 켜고 다시 측정하세요.
  3. 회복 틱 사이에 스킬을 한 번씩 사용해 집중 룬·마나 용광로 적용 전후의 MP 차감을 기록하세요. 스킬 입력에는 진화 적용 전 값을 넣으세요.
  4. 전투 영상에서 스킬 시전 시작 시각을 기록하고 사용자 지정 시전 계획에 입력하세요. 출처 확인을 위한 테스트는 같은 장착 상태에서 반복하세요.
조회한 스킬 소모량과 쿨타임

    진화 적용 전 재사용 대기와 비용을 우선순위대로 입력하세요. 시전·후딜 시간을 비우면 0초를 가정합니다. 사용한 유틸 스킬과 추가 회복도 포함하세요.

    시간별 마나 지속력

    쿨타임 기준은 조회한 스킬로 첫 시전을 0초에 계획합니다. 사용자 지정 간격은 진화 쿨감을 다시 적용하지 않습니다. 두 방식 모두 위의 최대·시작 마나와 회복 입력을 사용합니다.

    시전 시작 시각을 입력하는 경우, 비교할 스킬의 시각을 모두 입력하세요. 각성기와 초각성기는 시전 시각을 직접 입력한 경우에만 분석합니다.

    회복 버프가 겹치면 회복 1회량 중 가장 큰 값을 사용합니다. 겹친 상태의 실측값이 있다면 해당 구간에 입력하세요.
