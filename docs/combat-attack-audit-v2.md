2026-11-25 KST 기준. 비교 기준은 `8fca9e3`, 작업 브랜치는 `codex/xxapick-combat-audit-v2`다. 기존 운영 캐릭터 API를 통해 공식 OpenAPI 장착 상태를 읽었다. 직업·빌드는 현재 아크 패시브 이름을 사용했다. [공식 OpenAPI](https://developer-lostark.game.onstove.com/) · [11월 18일 패치](https://lostark.game.onstove.com/News/Notice/Views/13598)

## 표본과 검증 범위

- 103건 중 장착 빌드와 스킬을 분석할 수 있는 99건에서 30직업·60빌드를 확인했다. 후보 4건은 HTTP 502 또는 빌드 데이터 누락이었다. 성공 표본 중 4건은 수집 시 기대한 빌드와 실제 장착 빌드가 달라 실제 빌드에 반영했다.
- OpenAPI 스킬 행 2,394건은 일반·초각성 스킬 T 1,961건, 변신 39건, 각성기 198건, 초각성기 196건이다. 해당 표본 스킬은 HEAD 222건, BACK 717건, 비방향성 1,434건, HEAD·BACK 양방향 21건이다. 행 단위 집계에는 캐릭터별 동일 스킬이 포함된다. 데이터가 없는 공격은 이 집계 밖에서 UNKNOWN으로 유지했다.
- API가 반환한 트라이포드 선택지 13,950건을 기본 스킬과 대조했다. 개별 옵션 적용으로 방향 태그 또는 방향 적중 보장이 바뀐 경우는 150건, 스킬·옵션 이름 조합 41종이다. 타격별 실전 결과와 미수록 트라이포드 조합은 별도 확인이 필요하다.
- `scripts/audit-combat-attack-coverage.mjs`의 JSON은 빌드별 장착 스킬, 각성기, 초각성기, 명시된 특수 공격, 트라이포드 변경, 각인 적용 상태와 피해 지분 출처를 제공한다. 기존 로스터 또는 공식 API 응답을 보관한 로컬 JSON을 입력할 수 있다.

```sh
node scripts/audit-combat-attack-coverage.mjs <캐릭터-로스터-또는-응답-JSON> <보고서-JSON>
```

## 아이덴티티·각성기·피해 지분

- 디스트로이어 중력 가중 모드 기본 공격·볼텍스 그래비티와 블레이드 버스트는 아이덴티티 출처가 확인된다. 블러디 러쉬·포격 스킬은 변신 또는 특수 상태, 실버호크와 A.C.T는 독립 소환, 수라 그리드 화상은 DOT로 구분한다. 각 공격의 확인되지 않은 방향이나 타격 지분은 상위 공격에서 물려받지 않는다. [11월 18일 패치](https://lostark.game.onstove.com/News/Notice/Views/13598) · [공식 실버호크 패치](https://www.playlostark.com/en-gb/game/releases/welcome-to-paradise)
- 역천지체 표본의 천하섬멸옥은 각성기로 판정했다. 현행 파서가 각성기 이름으로 연결한 효과를 확인했다. 타격의 대가는 이 행에 적용하지 않으며 비중 기반 비교는 자동 테스트로 검증했다. 실제 레이드의 각성기 비중, 상태 가동률, 적용 수치 간 결합은 이 표본의 전투 로그가 없어 미확인이다.
- 피해 지분 검증은 공식 API 장착 스킬과 기존 전투분석 프리셋을 매칭했다. 98표본은 프리셋, 1표본은 장착 스킬 기반 추정이다. 공식 API는 개인의 실전 피해 지분을 제공하지 않는다. 합산된 양수 지분을 100%로 정규화했으며 이번 표본에 새 중복 표시는 없었다. 양수 지분이 붙은 28개 공격 이름은 방향을 확인하지 못했다. 사용자 입력 비중이나 실측 전투 로그는 이번 비교에 사용하지 않았다.
- 우선 남은 검증은 개별 타격의 방향·분배, 아이덴티티 및 소환/도트 적격성, 선택되지 않은 조합의 조건부 트라이포드, 각성기·초각성기 실전 지분 및 가동률이다. API의 공격 타입 부재와 데이터 미수록을 구분한다. 프리셋의 UNKNOWN 공격은 근거가 확인될 때까지 계산 가정을 유지한다.

## 기준 커밋과 회귀 비교

장착 노드 기준으로 60빌드의 API 응답을 브라우저의 캐릭터 적용·스킬 모델·피해 계산 흐름에 넣었다. 이론 배율은 55개가 같았고 5개가 바뀌었다. 양방향 태그가 복구된 디스트로이어 분노의 망치·중력 수련, 홀리나이트 심판자, 데빌헌터 전술 탄환과 강제 백어택이 복구된 차원술사 공간 검사에서 변경을 확인했다. 전 조합 TOP5 비교는 무사브와 공간 검사에서 별도로 수행했다.

무사브는 다섯 조합 모두 일격 Lv.2를 유지했다. 기존에도 71.35% 전체 행은 HEAD였고, 이번 변경은 별도 지분이 없는 연타와 마지막 타격의 방향을 확정했다. 공간 검사는 프리셋 비중 8.13%의 너머 베기가 선택 트라이포드에 따라 BACK 및 백 적중 보장으로 바뀌며 추천의 기대 피해가 달라졌다. 1·2위 조합은 표시 자리수에서 동률이다. 두 표본의 수치는 이론 기대 피해 배율이다.
