# 진화 추천 마나 검증

## 공식 규칙과 피해 계산

- 뭉툭한 가시 1·2레벨에서 치적 상한 80%, 기본 진피 9.5·19%, 초과 치적 전환 120·140%, 전환 상한 폐지, 다중 치명 제외를 확인했다. 공통 엔진은 해당 스킬의 치적과 조건부 치적을 반영한 후 초과분을 계산하고 기본 진피 및 다른 진피와 더한다. 추피와 적주피는 별도 피해 계수다. 예를 들어 치적 120%, 치피 250%, 다른 진피 25%의 2레벨 결과는 `(1 + 0.8 × 1.5) × (1 + 0.25 + 0.19 + 0.56) = 4.4`다. 이 경로에서 진피 중복 합산은 발견하지 않았다. 추천 카드가 구버전 기본 진피 15%를 덧붙여 표시하는 오류를 고쳤다. [11월 18일 공식 패치](https://lostark.game.onstove.com/News/Notice/Views/13598)
- 2·4·5티어 후보마다 현재 선택을 제거하고 새 노드 전체를 적용한다. 치적을 챙기면 같은 슬롯의 피해 증가나 마나 절감 노드를 포기하므로 그 차이가 후보의 피해 배율과 자원 비용에 직접 반영된다. 조합별 감점은 없다. 확정 치명과 뭉툭한 가시의 적용 순서, 일부 타격만의 치명, 다중 치명과 치명 적중 시 피해의 중첩은 기존 미검증 조건을 유지한다. 해당 피해 가정에 의존하는 후보는 마나 반영 순위에 넣지 않는다.
- 마나 용광로는 비마나 피해를 제외하고, 스킬의 증감 전 기본 마나 비용에 비례한 진피를 해당 스킬의 진피에 더한다. 공식 공개 툴팁의 2레벨은 기본 마나 10당 0.5%, 최대 24%, 마나 스킬 사용 시 최대 마나 2% 추가 소모, 낙인력 20%다. 1레벨의 10당 0.25%·최대 12%는 기존 데이터에 따른 값이며 현재 1레벨 장착 툴팁은 실측하지 못했다. 비용·진피의 게임 내부 반올림은 확인하지 못했다. [공식 전투정보실의 2레벨 툴팁](https://lostark.game.onstove.com/Profile/Character/%EB%A8%BC%EC%A7%80%EC%88%98%EC%82%AC)
- 같은 공식 전투정보실 표본의 스킬 툴팁에는 현재 레벨 98과 다음 레벨 125가 별도로 들어 있다. 기존 파서는 모든 문구 중 가장 큰 비용인 125를 택했다. 이제 현재 레벨의 마나 소모 필드를 사용하며, 이전 API 캐시도 원본 스킬 툴팁으로 다시 해석한다. 마나 용광로의 기존 일괄 최대 진피를 제거했다. 현재 레벨 원자료를 식별할 수 없는 조합은 미검증 후보에 표시한다. [공식 전투정보실](https://lostark.game.onstove.com/Profile/Character/%EB%A8%BC%EC%A7%80%EC%88%98%EC%82%AC)

## 자원 데이터와 적용 범위

| 항목 | 기존 구현과 현재 검증 |
| --- | --- |
| 스킬 소모량·주기 | API 스킬 툴팁에 현재 레벨 기본 마나와 쿨타임이 존재한다. `skill-cycle.js`는 신속, 보석, 트라이포드, 룬 일부, 스킬 연결을 이용해 사용 기회를 추정한다. 기존 주기는 실제 스킬 순서와 마나 잔량을 추적하지 않았다. |
| 소모 감소 | 끝없는 마나·금단의 주문·무한한 마력 수치는 진화 데이터에 있었으나 기존 추천은 소모량에 사용하지 않았다. 공식 2레벨 끝없는 마나 20%, 무한한 마력 16%를 대조했다. 감소 효과가 둘 이상이면 사용자가 확인한 중첩 방식이 필요하다. |
| 최대 마나·자연 회복 | 장비 툴팁에서 최대 마나와 자원 회복 옵션을 일부 파싱하지만, 캐릭터의 최종 최대치·전투 중 회복 틱·시작 잔량을 일괄 산출할 수 없다. 입력이 있을 때만 적용한다. |
| 파티 회복·음식·룬 | 서포터 파티 기여 모델은 공증·낙인·아이덴티티 중심이다. 룬 이름 및 장비의 자원 회복 옵션은 일부 읽지만 단죄·심판 발동, 음식, 서포터 회복 가동률을 자동 추정하지 않는다. 고정 효과는 실측 기본 소모·회복에, 별도 발동은 추가 회복의 시각과 회복량에 포함할 수 있다. |
| 직업별 자원 | 장착 스킬의 마나 여부를 개별 판단한다. 아르카나 카드 수급, 스킬 연동 쿨감, 아이덴티티와 마나의 동시 변화는 별도 검증이 필요하다. 비마나 직업의 자원을 마나로 환산하지 않는다. |

이론 모드는 스킬별 기대 피해와 기존 쿨감 모델을 사용한다. 마나 비교는 동일한 입력 구간의 시작 잔량, 최대치, 회복 틱·추가 회복, 스킬별 시각·간격·비용을 사용한다. 회복을 먼저 적용하고 준비된 스킬의 마나가 모자라면 가능한 시각으로 지연한다. 구간 내 실제 사용 횟수와 제한 없는 사용 횟수의 비율을 해당 스킬의 이론 피해 지분에 적용한다. 같은 시각의 스킬은 입력 순서로 처리한다. 마나 지연 없는 후보가 우선이며, 같은 조건 안에서는 마나 반영 피해가 높은 후보부터 표시한다. 마나 비교를 해제하면 이론 정렬이 복원된다.

마나 반영 배율은 입력 구간의 비교 지표다. 애니메이션이나 보스 패턴, 적중으로 발동하는 회복의 자동 타이밍과 직업별 회복·자원 상태 머신을 재현하지 않는다. 관련 입력이나 피해 정보가 빠지면 이론상 결과와 미검증 조건을 표시한다. 서포터의 종합 파티 기여와 골드 효율 시뮬레이터는 기존 계산 경로를 사용한다.
