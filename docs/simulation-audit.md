## 수정과 전후 비교

- 딜러 A/B의 기존 식은 노드 기대 피해 비율, 보석별 추정 비율, 공식 전투력의 추정 변화 비율을 곱했다. 반지·각인 효과는 표시 수치에만 더했다. 변경 후에는 실제로 모델링한 악세·각인을 적용한 B의 기대 피해를 A와 나누며, 보석은 동일 지분의 분석 배율을 별도로 반영한다. 재련·귀걸이 기본 공격력/무기 공격력·미적용 조건부 각인 등 직접 피해 모델이 없는 변경은 전투력·비용에만 남고 화력 미반영 사유를 표시한다.
- 서포터 A/B에서 딜러 노드 배율을 제거했다. 동일한 서포터 기여 모델에 A·B의 노드와 장비를 각각 넣고 복합 변화율을 다시 계산한다. 따라서 파티 종합 버프 기준 TOP5와 복합 지표는 목적에 따라 다를 수 있다.
- 같은 반지·목걸이·귀걸이 칸의 대안을 중복 반영하던 경로를 수정했다. 목표·예산·A/B는 선택한 후보 중 비용 효율에 따라 해당 칸을 한 번만 반영한다. 보석 레벨 증가 전후는 같은 전투분석 프로필로 비교한다.
- 치적 220%와 240%인 동일 지분의 두 스킬과 원한 유물 Lv.0을 고정해 36개 후보를 독립 계산했다. 현재 세팅 `입식 타격가 Lv.2`의 기대 배율은 **11.3510**, 추천 1위 `예감2·한돌1 / 회심·달인 / 뭉툭한 가시2`는 **18.0055**이다. 장비를 고정한 A/B도 **+58.62%**로 일치한다. 이 조합에 표본 반지 상상 교체를 넣으면 공통 엔진 결과는 **18.2071**, A 대비 **+60.40%**다. 같은 전투력 추정치로 변경 전 혼합식을 재현하면 **+61.42%**였다.
- 패치 전후 황제 아르카나 TOP5는 [계산 구조 문서](calculation-engine.md#추천-전후-비교)에 기록되어 있다. 이번 변경은 기존 딜러 TOP5의 계산 목표나 정렬을 바꾸지 않는다. 실제 전투 시간 기준 최적 조합을 비교할 수 있는 시뮬레이터는 현재 사이트에 없다.

## 검증 및 남은 범위

- 기존 21개 스위트를 유지하고 시뮬레이터 스위트를 추가했다. 고정 시드로 치적 90·100·120·200·220·300%의 2점 피해 분포, 뭉툭한 가시, 재련 기대 시도를 반복 검증했다. 창술사 특수 치명, 버프 전후, 동시 선택, 미지원 입력도 확인한다. 난수는 테스트에서만 사용한다.
- 기존 자동 테스트를 포함한 22개 스위트와 PC·모바일 브라우저 테스트, 브라우저 번들 1개·API 번들 8개의 로컬 빌드 및 Vercel 함수 파일 추적을 통과했다. 데스크톱에서는 TOP5를 모두 A/B로 재현했다. PC·모바일 양쪽에서 반지·각인 선택을 확인했고 서포터 A/B와 파티 기여 패널도 대조했다.
- 치명타 적중 시 효과의 발동 횟수 제한은 [11월 18일 공지](https://lostark.game.onstove.com/News/Notice/Views/13598)에서 확인된다. 회심·팔찌가 여러 치명 단계의 피해 배율에 어떻게 적용되는지, 확정 치명과 뭉툭한 가시 우선순위, 일부 타격 전용 효과, 패치 후 직업별 실측 딜 지분 및 버프 중첩·가동률은 미검증이다. 창술사 특정 코어·트라이포드 규칙의 적용 조건은 [11월 19일 공지](https://lostark.game.onstove.com/News/Notice/Views/13601)를 사용한다.
- 전투 시간별 실제 스킬 사용 순서, 총 피해량과 DPS를 산출하는 기능이나 게임 실측 로그가 없다. 쿨타임·공격속도·조건부 효과는 사이트의 기대값 모델 범위에서 검증한다. 운영 배포 및 운영 API 검증은 이번 작업에서 수행하지 않는다.
