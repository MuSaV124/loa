## 공식 규칙과 가정

- 일반 치명 확률을 100으로 나눈 값을 `r`, 치명타 피해 배율을 `c`로 둔다. 기본 피해가 1일 때 `floor(r)`회만큼 `c−1`을 확정 추가하고 다음 단계가 `r−floor(r)`의 확률로 적용된다. 평균은 `1+r×(c−1)`이다. 예를 들어 치적 120%, 치피 250%에서는 80% 확률로 2.5배, 20% 확률로 4배여서 평균은 2.8배다. 치명타 적중 시의 발동 횟수는 한 공격당 최대 한 번이다.
- 뭉툭한 가시 Lv.1/Lv.2는 기본 진피 9.5/19%, 치명타 확률 최대 80%, 초과분의 120/140%를 상한 없이 전환한다. 다중 치명타를 끈다. 낙원도 공식 예외이며, 이 사이트의 순위는 레이드용이다. 낙원의 유산 가면·호각은 계산기 입력에 포함되지 않는다.
- 기본 치피와 치피 증가를 더해 치명 단계당 증가분을 산출한다. 피해 엔진은 진화형 피해, 추가 피해, 적에게 주는 피해, 속성 피해, 공격력 증가와 스킬 피해를 별도 배율로 처리한다. 기존 출처별 곱연산과 버킷 가정은 유지했고 게임 서버의 전 배율 순서·중첩을 공식 검증하지 못했다. 특히 회심·팔찌류의 치명 적중 주피는 첫 치명 부분에 한 번 곱하고, 다중 치명 추가분에는 기본 치피 증가분을 쓰는 모델이다. 발동 횟수와 피해 배율 적용 범위는 별개이므로 이 중첩은 실측 검증이 필요하다.
- 아르카나 도태를 치적 +20%·치피 +50%로 갱신했다. 도태·재상·제후가 겹치는 기존 기대 가동률 모델은 유지한다. 분당 드로우와 카드 확률은 표본 보정이며 이번 패치의 실측값이 아니다. 11월 19일 황제의 자비 5레벨 수정과 아르카나·서머너 시너지 지속시간 수정은 실전 가동률 검증이 필요하다.
- 창술사에서 확정 치명과 치적 1%p당 피해 0.6% 전환을 스킬 효과로 파싱한다. 굉열파·적룡포·사두룡격은 장착 트라이포드, 적룡필살은 도약, 진화의 끝은 적룡포의 진화하는 창술 장착 여부를 확인한다. 철량추·절룡세의 일부 타격 규칙은 타격별 지분이 없어 계산에서 보류한다. 확정 치명과 뭉툭한 가시가 동시에 적용되는 우선순위는 공지에 없다. 해당 조합은 80% 제한 경로를 사용하며 미검증으로 표시한다.
- 패치의 트라이포드 변경 중 인파이터·데빌헌터·블래스터·호크아이·건슬링어·아르카나·블레이드·도화가의 수치형 치적은 캐릭터의 최신 공식 툴팁을 입력으로 사용한다. 80%는 공지에 열거된 트라이포드의 변경값이고 모든 치적 효과의 상한은 아니다. 일부 타격 전용 수치를 전체 스킬 효과로 파싱하는 경우의 상세 피해는 미검증이다.
- 버서커·디스트로이어·슬레이어·인파이터·브레이커·블래스터·스카우터·건슬링어·아르카나·소서리스·블레이드·리퍼·기상술사의 깨달음과 인파이터·창술사·차원술사의 그리드 변경은 현재 API 툴팁으로 읽는다. 모든 다중 대상, 스탠스, 타격 분할, 자원·중첩 및 각성 제외 패턴의 자동 반영을 확인하지 못했다. 차원술사 기본 스킬 계수 및 전투분석 지분은 패치 이후 실측 자료가 없어 갱신하지 않았다.
- 홀리나이트·발키리의 공증 스킬 기본 쿨타임을 각각 30초로 갱신했다. 바드·도화가의 지점형 공증은 첫 판정 6초 기준으로 계산하며 위치 이탈·늦은 진입은 실측 검증이 필요하다. 낙인은 장착 툴팁과 현재 쿨타임으로 단일 스킬 가동률을 추정한다. 여러 낙인과 아이덴티티·그리드 낙인의 겹침, 하프 반복 적중, 발키리 신의 증명 등의 파티 중첩은 전체 타임라인이 없어 미검증이다.
- 11월 18일 공지에는 일반 각인 자체의 수치 변경이 없다. 조건부 각인의 스킬별 충족률, 기본 공이속 114% 가정, 파티 시너지 중첩·자버프 가동률, 실측 딜 지분을 가중치로 쓰는 방식, DPS용 쿨감 상한은 검증 미완료다. 스탯 환산·재련·보석·골드 비용·전투력 표본을 패치와 별도로 관리한다.

### 뭉툭한 가시와 입식 타격가 재검증 (2026-11-20)

- 진화 노드 중 `critCap`을 가진 뭉툭한 가시만 다중 치명타를 비활성화한다. 나머지 노드의 레벨별 데이터를 대상으로 치적 120·220·300%를 공통 엔진에 전달해 단계와 기대 피해를 검증한다. 스킬 자체의 확정 치명·치명타 불가 규칙은 공격 단위로 적용한다.
- [11월 18일 공식 패치](https://lostark.game.onstove.com/News/Notice/Views/13598)의 80% 제한·초과 전환과 다중 치명타 규칙을 `damage-math.js` 및 `data/evolution.json` 입력으로 검산했다. 입식 타격가 Lv.1/Lv.2는 최대 6중첩 가정에서 진피 10.5/21%를 한 번 합산하며, 일반 스킬은 100% 초과 치적을 공통 엔진에 전달한다. 두 레벨 모두 원시 치적 80·100·120·150·200·220·300%를 검사했다.
- `app.js`의 전투분석 지분 연결이 이름이 비슷한 다른 스킬을 먼저 선택해 치적·치피를 누락하는 문제를 재현했다. 정확히 일치하는 이름을 우선하고, 진피 요약 합계에는 스킬 지분 가중 뭉툭한 가시 전환량을 반영했다. 220%/350%, 240%/450%의 동등 지분 표본에서 수정 전후 입식 타격가 현재 세팅은 9.2807 → 11.3510이었다. 동일 후보군의 1~4위 조합은 유지됐고, 5위가 예감2·한돌1 / 달인·분쇄 / 뭉툭한 가시(14.4418)에서 예감1·한돌2 / 달인·분쇄 / 입식 타격가(17.5975)로 바뀌었다.
- 마나 회복을 입력한 10초 테스트에서 마나 기술의 5회 예정 시전 중 서포터 없음 2회, 바드 3회, 도화가 4회, 홀리나이트와 발키리 5회를 적용하고, 각 스킬에 이미 계산된 피해를 시전 횟수로 가중하는지 검증했다. 회복량과 시각은 재현용 입력이다.

### E. 확인한 오류와 수정

- 입타와 인파이팅을 무조건 최대값으로 적용하던 경로를 피해 가중 중첩·가동률 입력으로 바꿨다. 입타 Lv.2 6→3중첩은 진피 21→16.5%다. 모의 고치적·고치피의 같은 입타 조합은 44.6213→43.7740이었다. 인파이팅 Lv.2 가동률 100→90%는 진피 18→16.2%, 같은 조합 44.0565→43.7176이다.
- 마나 점수보다 부족 여부를 먼저 정렬해 실제 마나 반영 피해가 높은 조합이 밀렸다. 마나 반영 피해를 우선하고 동점에서만 지연 여부를 적용했다. 도화가 표본은 7.3705→7.5143으로 바뀌었다. 후자의 30.24초 부족은 기록되지만 이 구간에서 횟수 손실은 없었다.
- 일격의 방향성 스킬 치피가 전역에 적용되어 비방향성 스킬에도 +32%p가 들어갔다. 실제 스킬 툴팁의 공격 유형을 확인한다. 방향성 혼합 모의 표본 기준 치피는 292/352/312%에서 260/352/280%로 바뀌었다. 공격 방향을 확인할 수 없는 일격 후보는 이론에 표시하고 마나 순위에서 제외한다. [일격·스킬 툴팁 공개 표본](https://lostark.game.onstove.com/Profile/Character/%EB%B3%B8%EC%B0%BD)
- 마나 용광로의 스킬별 진피는 피해 수식에 이미 적용되지만 계산 요약 합계에서 빠졌다. 진피 합계를 스킬 지분 가중값으로 계산한다. 또 쿨타임 모델이 없더라도 장착 스킬이 모두 비마나로 확인된 경우, 마나 스킬 전용 쿨감을 수동 지분에 가산하지 않는다.
- 진화 포인트가 알려진 캐릭터에서 보유량 초과 후보를 걸러내고, 5티어 추천 레벨을 실제 잔여 포인트로 제한했다. 안정된 관리자는 직접 피해 비교에 포함하고 게이지 감소의 딜 영향 미검증을 명시했다. 서포터 전용 추천도 입타의 입력 중첩을 낙인에 적용하되 파티 기여와 개인 피해는 분리한다.

### F. 결론과 재현

뭉가는 저치피·고치적에서 초과치적을 진피로 전환하면서 앞서는 구간이 넓다. 낮은 치적에서도 19% 기본 진피 때문에 다른 노드의 고유 효과가 비활성화된 표본에서 앞설 수 있다. 공·이속을 넘기는 고치피 캐릭터는 음돌, 고비용 주력기와 충분한 회복은 마용, 낮은 치적과 입식 고중첩은 입타가 앞서는 사례를 확인했다. 피격 이상으로 입식 중첩을 잃고 정면 승부 적중을 유지할 수 있으면 인파이팅이 앞설 수 있다. 안관은 개인 피해 가산이 없어 뭉가를 넘어서는 일부 극단적 구간에서도 직접 피해를 올리는 다른 노드와 비교해야 한다.

[당시 전체 결과](tier5-audit-data.json)는 공식 툴팁과 독립 피해 검산, 브라우저 11표본의 기존 추천 조합 6,138개, 서포터별 마나 모의를 포함한다. `npm test` 26개 스위트, PC·모바일 UI, 로컬 브라우저 및 API 8개 번들·파일 추적, `git diff --check`를 통과했다. `vercel build`는 로컬 프로젝트 연결 설정이 없었다.

실제 전투 로그·트리시온 실측은 포함하지 않았다. 특히 회심의 추가 치명 단계 피해 적용, 확정 치명과 뭉가의 우선순위, 직업별 독자 자원·연동 스킬, 실제 버프 상관관계는 별도 검증이 필요하다.

- **중력 수련**은 한 문장에 묶인 두 스킬을 각각 매칭한다. 실제 중력 수련 표본에서 두 공격의 30%p·28% 툴팁을 읽었다. 해당 전투분석 자료는 중력 가중의 묶음 지분 75.42%만 제공해서 둘에 일괄 적용하지 않았다. 다른 공격은 두 효과 대상에서 제외한다. `classScopedDamageTargets` 및 `passiveEffectsForSkill` 회귀로 확인했다.
- **환류 강화·초각성**은 실제 API 표본의 `SkillType` 0/1/100/101을 일반/초각성 스킬/각성기/초각성기로 구분했다. 환류는 일반과 초각성 스킬에 적용한다. 초각성 전용 효과를 광범위한 아이덴티티 이름 목록으로 매칭하던 경로를 제거했다. `extractCombatSkillEffects`에서 타입 유무를 보존한다.
- **중복과 조건**은 대상 적주피를 일반 스킬 피해로 다시 읽던 중복을 제거했다. 집중 스킬의 적주피 +7% 단일 문구는 1.1449배에서 1.07배가 됐다. 격분, 맑은 날, 황제의 자비와 같이 가동률이 필요한 효과는 발동·적용 범위 미확인으로 표시하고 확인된 효과로 기준값을 낸다. 마나 분석에서는 해당 결과를 가정 기반으로 표시한다.
- **부분 타격**은 창술사 두 트라이포드의 기존 예외를 유지하고, 인파이터 내려찍기, 데빌헌터 어퍼킥, 블래스터 폭발, 블레이드 회오리, 아르카나 지속시간별 치적을 전체 스킬 치적·치피에서 분리했다. 타격별 지분을 조회할 수 없을 때 계산된 값은 미확인 조건이 빠진 추정치다.
- **서포터**의 재사용 대기시간 보정은 해당 공증 스킬에 선택한 `빠른 준비`만 참조하도록 고쳤다. 관련 없는 스킬의 트라이포드가 공증 쿨타임을 6초 단축하던 보정 경로를 막았다. 가동률·교체 순서는 시간표 없는 평균 모형으로 유지했다.
- **조회 재현**은 요청 및 실제 데이터 파싱을 `parseCharacterArmory`에서 연결한다. 실표본 원본을 새 API 파서와 현행 브라우저 추천에서 재생했다. 현재 서버 응답의 파생 효과 수치를 복사해 사용하는 방식은 피했다.

### C. 범위와 결과

[직업별 재생 집계와 모의 빌드 전후 TOP5](class-damage-audit-results.json)에 실표본의 직업별 검증 범위와 모의 빌드의 비교 기준, 스킬 지분 출처, 미확인 효과 및 추천 배율을 기록한다. 공식 OpenAPI 원본은 배포 조회 응답 v6.1.1에서 추출해 v6.1.4 로컬 파서로 계산했다. 레이드 시전별 로그가 없으므로 피해 배율은 스킬 지분과 장착 효과를 사용한 상대 추정이다.

### E. 남은 범위

- 실표본이 없는 카탈로그 빌드 17개는 실제 장착 상태 확인이 필요하다. 워로드 전투 태세, 버서커 광기, 브레이커 수라의 길, 배틀마스터 오의 강화, 인파이터 충격 단련, 창술사 절제, 호크아이 죽음의 습격, 건슬링어 피스메이커, 바드 진실된 용맹, 서머너 넘치는 교감, 아르카나 황후의 은총, 소서리스 환류, 블레이드 잔재된 기운, 도화가 만개, 기상술사 이슬비, 환수사 환수 각성, 가디언나이트 업화의 계승자다.
- 현재 장착한 각인·보석·트라이포드·특성은 API에서 읽을 수 있다. 타격별 피해 지분, 스택 분포, 조건부 공격의 실제 가동률, 변신·스탠스 전환 시점, 소환수와 본체의 상세 지분, 서포터 버프 교체·위치·실제 적용 대상은 레이드 로그 또는 통제 실험이 필요하다. 표본 44개에서 구체적인 미해결 효과 문구를 기록했다. 그 외 표본에도 집계되지 않은 실전 조건이 있다.
- 스킬별 기본 상수와 패치 후 피해 지분은 OpenAPI의 장착 툴팁과 별개다. 현행 추천은 대표 전투분석 지분 또는 장착 스킬 추정 지분을 사용한다. 특히 차원술사의 −5% 같은 기본 피해 조정은 최신 전투 지분을 다시 확보해야 가중치에 정확히 반영할 수 있다.
- 4종 서포터 지점형 공증 교체나 실제 낙인의 유지 시간을 재는 다중 사용자 전투 로그는 확보하지 못했다. 플레이어 한 명의 지원 효과 모델과 딜러의 마나 회복 모델을 따로 검증했다. 회심의 추가 치명 피해 적용은 A/B로 유지한다.

### F. 판정과 재현

30개 직업 모두 OpenAPI 응답을 현행 파서와 TOP5에 연결하고 모의 두 빌드를 재생했다. 전 직업의 모든 특수 피해나 각 빌드의 실측 DPS는 확정할 수 없다. 확인 가능한 스킬 유형·범위·중복 오류를 수정했고 미확인 항목을 표시한다.

`node scripts/audit-class-recommendations.mjs <결과.json> [원본 스냅샷.json]`으로 60개 모의 빌드 및 선택한 스냅샷을 재생한다. 승인된 공개 조회 경로/닉네임에 한해 `node scripts/collect-class-audit-snapshots.mjs <원본 스냅샷.json>`으로 새 원본을 수집할 수 있다. 시점별 상세 스냅샷과 캐릭터별 실표본 결과는 로컬 감사에 사용했다. 기존 `audit-tier5-evolution.mjs`로 25,344건과 모의 전투 6,138개를 다시 계산해 직전 감사와 이론 TOP5가 모두 일치하는 것을 확인했다.
