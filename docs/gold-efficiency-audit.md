# 골드 효율 시뮬레이터 검증

## 시세

- 재료는 서버에서 공식 `POST /markets/items`의 `CurrentMinPrice`와 `BundleCount`를 사용한다. 등록 매물의 묶음 최저가로 예상 비용을 계산한다. 어제 평균가나 최근 체결가는 현재 최저 등록가의 대체값으로 쓰지 않는다. 실제 체결가, 재고 깊이와 대량 구매의 가격 변동은 확인 범위 밖이다. [Open API 사용 가이드](https://developer-lostark.game.onstove.com/usage-guide) · [시장 엔드포인트 변경 이력](https://developer-lostark.game.onstove.com/changelog)
- 운영의 공개 스냅샷 37행을 대조한 결과 저장 시각은 2026-10-04 11:50:53 KST였다. 일반/위대한 돌파석은 각각 66110225/66110226, 일반/결정 파괴석은 66102006/66102007, 일반/결정 수호석은 66102106/66102107이었다. 두 돌 묶음은 각각 100개, 파편 주머니는 한 묶음에 주머니 한 개였다. 해당 스냅샷의 ID를 검증 기준으로 삼아 전체 이름, ID, 정상 가격, 묶음 수량을 함께 검사한다. 파편 주머니 소·중·대는 기존 1,000/2,000/3,000개를 사용한다. 원본 API 키가 없어 현재 응답과 매물 가격은 실측하지 못했다. [공개 운영 스냅샷](https://loa-beige.vercel.app/api/market-snapshot)
- GitHub Actions 설정은 매시 7분과 37분에 Vercel Blob 스냅샷 갱신을 요청한다. CDN은 스냅샷을 60초 보관하고 최대 300초 동안 백그라운드 갱신을 허용한다. 실패 시 서비스의 이전 섹션과 조회 시각을 유지한다. 열린 화면은 5분마다 공유 스냅샷을 확인한다. 재료 섹션이 40분 이상 오래된 경우 기존 재료 경로를 공유 캐시 주기(30분) 내에서 제한적으로 확인한다. 운영 스냅샷 정체의 외부 원인은 확인하지 못했다. 공식 동기화 지연과 사이트 캐시 지연은 별개다. [공식 동기화 FAQ](https://developer-lostark.game.onstove.com/faq)
- 429는 응답의 요청 한도 재설정 시각과 `Retry-After`에 따라 같은 서버 프로세스에서 후속 요청을 중단한다. 인증 실패나 503에도 일시 중단하고, 동시 강제 조회는 같은 요청에 합류시킨다. 새 가격의 조회 시각은 KST로 표시한다. 단가나 묶음이 바뀐 재료를 쓰는 재련 후보만 갱신한다. 필수 시세나 귀속 재료가 없으면 비용을 미확정으로 두고 추천에서 제외한다. [공식 요청 한도](https://developer-lostark.game.onstove.com/getting-started/#throttling)

## 기대비용과 순위

- 일반·완갑 재련은 첫 성공 시도의 분포를 만들고 천장 시도의 남은 확률질량을 포함한다. 성공 시도마다 일회성 성장 재료와 반복 시도 재료를 합산한다. 해당 결과에서 귀속 보유량을 차감하고 남은 수량을 구매 묶음으로 올림한 뒤 골드 비용을 확률로 가중합한다. 파편은 조회된 소·중·대 주머니로 필요한 수량을 충족하는 최저가 조합을 계산한다. 여러 완갑 단계는 재료별 총 필요 수량을 합성하므로 재고를 단계마다 새로 적용하지 않고 남은 거래 묶음도 구간 안에서 공유한다. 실링은 별도 집계한다.
- 예를 들어 테스트 시세에서 두 시도의 성공 확률이 각각 50%인 경우, 비용은 178G와 399G여서 정확한 모델 기대값은 288.50G다. 기존처럼 평균 시도 수에 귀속을 차감하고 소수 단가를 곱하면 257.23G다. 동일한 성능 증가율의 270G 후보가 있다면 이 변경으로 순위가 바뀐다. 지표만 바꾸는 경우에는 같은 성능 지표 내에서 기존 1%당 골드의 오름차순과 신규 10만 골드당 상승률의 내림차순이 동일하다.
- 완갑 15→16은 공식 표의 기본 성공률 3%, 성장 파편 328,000개, 1회 9,280G를 사용한다. 전설 등급에서는 뒷단계에 필요한 귀속 재료를 확인하며, 유물 이상으로 이미 해방한 완갑에는 같은 해방 비용을 중복 적용하지 않는다. 대체 재료가 있으면 사령의 잔영부터 소진한 후 부족분을 죽음의 손으로 채운다. 효율표의 완갑 후보는 숨결을 쓰지 않는 기준을 유지한다. [완갑 재련과 한계 해방 공식 표](https://lostark.game.onstove.com/News/Notice/Views/13508#anchor-1785742364253)
- 일반 재련 전투력은 현재 캐릭터의 공식 전투력과 같은 직업·부위·강화 구간의 기존 보정 표본을 사용한다. 완갑은 공식 능력치 기준점과 장착 캐릭터의 기본 공격력·무기 공격력을 사용하며 중간 단계 보간 및 전투력 환산은 추정이다. 보석·악세·각인 A/B의 스킬 피해는 기존 v6.0.0 공통 엔진 사용 범위를 유지한다. 전투력, 기대 피해, 서포터 복합 기여는 각각 순위를 산정한다. ## 검증이 남은 항목

- 과거 시세를 사용한 재료 ID 외에 현재 운영 API의 최저 등록가, 전량 구매 가능 여부, 정기 갱신 인증 상태는 미검증이다.
- 일반·완갑 재련은 각 단계 장인의 기운 0%부터 시작하며, 기존 실패 보정과 장인의 기운 계수 0.46511 및 숨결 상한은 게임 내부 반올림까지 확인한 공식 수치가 아니다. 단계별 가능한 결과에 대한 수학적 기대값은 이 입력을 전제로 한다. 수동 모드의 숨결 및 여러 완갑 구간의 단계별 숨결 비용은 선택된 전략에 대한 추정이며, 재고를 포함한 전체 구간 최적 정책을 보장하지 않는다.
- 파편 보유량이 최소 소모량을 크게 넘는 긴 완갑 구간은 브라우저 백그라운드 작업에서 계산한다. 선택 조건을 바꾸면 이전 작업을 취소한다. 구간과 보유량에 따라 결과가 표시되기까지 시간이 걸릴 수 있다.
- 상급 재련은 기존 확률 상태 모델로 기대 재료량을 구하되, 귀속 차감과 묶음의 확률분포까지 풀지 않고 평균 수량으로 비용을 환산한다. 목표·예산 플래너에서 독립 후보 사이 재고는 기대 차감량 기준이다.
- 무기 24→25와 완갑 15→16의 순위는 동일 캐릭터의 시세와 상승률 표본이 확인되어야 결정할 수 있다. 공식 전투력의 전체 환산식과 완갑 +16 실측값이 확보되기 전까지 기대 피해의 증가율을 전투력과 같은 수치로 사용하지 않는다.
