## 캐릭터 자동 분석

- 현재 레벨의 스킬 마나를 우선 읽고 다음 레벨 비용을 제외한다. 선택된 트라이포드나 집중 룬에서 적용 범위가 명확한 단일 정률 소모 효과는 명목 비용에 반영한다. 조건부·복수 효과와 중첩이 불명확한 비용은 입력칸을 비운다. 효과 발동 순서·마나 반올림·각인이나 장비와의 전체 중첩은 확인되지 않았으므로 최종 게임 실측 비용과 구분한다.
- 자동 추출한 비용은 스킬별 입력 줄에 채운다. 기본 쿨과 장착 상태의 쿨 모델은 스킬 목록에서 확인할 수 있다. 실제 사용 첫 시각과 간격은 별도 값이다. 쿨타임을 사용 간격으로 복사하지 않는다.
- 관측된 마나 스킬이 있는 일반 직업은 자동 비용 분석이 가능하다. 소서리스·워로드·블레이드·아르카나는 마나와 별도 상태 자원을 구분한다. 데모닉·스카우터·소울이터는 변신·상태 전환을 별도 처리해야 하므로 고정 입력을 기반으로 한 비교는 가정으로 표시한다. 인파이터·기공사·브레이커의 특수 자원은 MP로 환산하지 않는다. 나머지는 장착 툴팁 범위에서만 마나 여부를 표시한다.
- `mana-character.js`의 검증 프로필 조회는 닉네임·클래스·스탯·장착 스킬·트라이포드·룬·보석·장비 서명과 패치 및 검증 유효 기간을 대조한다. 현재 저장소에는 공식 수치와 함께 운용 순서·회복 틱을 실측해 등록할 수 있는 프로필이 없다. 일치하는 레코드가 확보되면 자동 입력을 사용하고, 현재 닉네임만 조회한 결과는 이론 순위와 미확인 항목을 표시한다.

가동률 기본값은 비워 둔다. 실제로 회복을 받은 시각과 해당 시점의 실측 회복량은 사용자 입력으로 처리한다. 지속 효과는 해당 구간의 틱만 바꾸고, 즉시 효과는 발동 이벤트를 한 번 넣는다. 같은 서포터 효과가 겹치는 구간은 회복량을 반복해서 더하지 않는다. 타 스킬과의 공식 중첩, 틱 간격의 변화, 해우물의 백분율 기준 세부 동작은 확인되지 않았다. 가동률만 입력한 일정 구간 분산, 회복 속도 수치를 동일한 간격의 틱당 회복 증가로 환산하는 방식, 해우물을 대상 최대 마나에 비례시키는 방식은 모두 가정 모드에서만 사용한다. 음식은 사용 상태에서 실측한 회복 1회량으로 계산한다.

## 순위 산정

- A는 기존 공통 피해 엔진의 이론 순위다. 동일한 캐릭터에서 1·3티어를 고정하고 2·4·5티어의 각 대안을 통째로 교체한다. 뭉툭한 가시 및 마나 용광로 공식에는 별도 가점이나 감점이 없다. [다중 치명 공식 패치](https://lostark.game.onstove.com/News/Notice/Views/13598) · [창술사 핫픽스](https://lostark.game.onstove.com/News/Notice/Views/13601)
- B는 해당 입력 구간의 마나 반영 순위다. 정한 시간의 회복 이벤트를 먼저 적용하고, MP를 쓰는 스킬은 입력으로 정해진 사용 순서를 유지한다. 앞선 MP 스킬이 부족하면 해당 순서를 건너뛰어 다른 MP 스킬에 자원을 쓰지 않는다. 비마나 사용 횟수는 MP 지연으로 줄이지 않는다. 실제 사용 횟수와 제한 없는 횟수의 비율을 각 스킬의 기대 피해 지분에 곱한다. 지연 없는 조합이 우선이며 그 안에서 마나 반영 피해로 정렬한다. 이 모델은 보스 패턴·직업별 자원·애니메이션 전체를 재현하는 DPS 로그가 아니다.
- 데이터가 부족한 경우 A를 표시하고 C에서 누락 이유를 보여준다. 실제 적용 시각과 양이 없는 가동률 시나리오는 별도로 볼 수 있다. 같은 입력에서 서포터 적용 여부만 바꾼 값이 증가한 경우에만 카드에 해당 차이를 표시한다. 부족 시점, 지연과 감소한 시전 횟수, 이론 및 마나 순위를 표시한다.

## TOP5 비교

기존 테스트와 동일한 높은 치적 두 스킬 표본이다. 모든 행의 4티어는 별도 표시한 경우를 제외하고 회심·달인이며, 5티어는 뭉툭한 가시다. 서포터별 시각과 회복량은 브라우저 테스트 입력이다. 표의 결과는 실전 직업별 우열을 뜻하지 않는다.

| 순위 | v6.1.0 이론 및 바드·홀리나이트·발키리 표본 | v6.1.0 서포터 없음·회복 0 | v6.1.0 도화가 표본 |
| ---: | --- | --- | --- |
| 1 | 끝마2·최훈1 | 예감2·한돌1 | 끝마1·금주1·최훈1 |
| 2 | 끝마1·최훈2 | 금주1·예감2 | 끝마1·금주1·예감1 |
| 3 | 끝마2·예감1 | 예감1·한돌2 | 끝마1·금주1·한돌1 |
| 4 | 끝마2·한돌1 | 금주1·예감1·한돌1 | 끝마1·금주2 |
| 5 | 끝마2·금주1 | 금주2·예감1 | 끝마1·금주1·최훈1 / 달인·분쇄 |

- 이전 이론 TOP5는 위와 같다. 이전 마나 모델의 무회복 1위는 끝마1·금주2였다. v6.1.0의 무회복 표본에서는 MP 스킬의 순서를 보존하면서 지연하므로 같은 시작 상태의 대안 순위가 달라졌다. 낮은 치적의 테스트 표본은 마나 조건을 반영해도 입식 타격가가 1위였다. [이전 비교표](mana-recommendation-audit.md)
- 마나가 충분하면 실전 입력 TOP5가 A와 일치한다. 마나 용광로는 480 미만 기본 MP 스킬에 2레벨 최대 진피를 적용하지 않으며 마나 스킬마다 최대 마나 2% 소모를 더한다. 동일한 8초 구간과 동일한 실측 회복량의 홀리나이트·발키리는 동일하게 계산된다.

## 변경 파일과 검증

- `api/character.js`와 `public/mana-character.js`가 원자료 기반 분석과 프로필 확인을 담당한다. `public/support-mana.js`가 서포터 규칙과 출처를 보관한다. `public/mana-recommendation.js`는 기존 스킬별 피해 지분에 자원 지연을 적용한다. `public/app.js`, `public/index.html`, `public/style.css`에 선택 및 출처 표시를 연결했다.
- `scripts/test-mana-environment.mjs`는 공식 API·인벤 모의 응답, 자료 누락·갱신 유효 기간, 모든 서포터, 즉시·지속 효과, 음식, 48개 두 스킬 시나리오의 회복 증가 단조성을 검사한다. `scripts/test-skill-ui.mjs`는 PC·모바일 공식 값 자동 입력, 가동률 0·100, 자동 서포터 전환과 TOP5, 골드 효율 회귀를 실행한다.
