## 중복 제거와 시전 범위

공식 `ArmorySkill`은 이름, 아이콘, 레벨, 조작 유형, `SkillType`, 트라이포드, 룬, 툴팁을 제공한다. 공식 스킬 ID와 장착 슬롯은 제공하지 않는다. 직업·스킬명·유형으로 묶은 UNKNOWN 189종이 모두 캡처 내부의 서로 다른 아이콘과 대응했다. 동일 캐릭터 안의 동명 행은 0개였다. 아이콘 일치는 보조 검산이다. [공식 Armory 스키마](https://developer-lostark.game.onstove.com/swagger-doc/endpoints/armories)

레벨 2 이상, 선택 트라이포드 또는 장착 룬은 장착 추정의 단서다. 게임에서 슬롯을 확인하지 못한 스킬은 추정 상태를 표시한다. 자동 계획은 이 단서가 있는 일반·발현·초각성 스킬로 제한한다. 가디언나이트 발현은 일반 상태 슬롯에 담을 수 있고, 화신은 상태 전용이다. 상태 전용·아이덴티티·각성기(100)·초각성기(101)는 별도 표시한다. 초각성 스킬(1)은 초각성기(101)와 별개다. 기본 공격은 독립된 힌트로 처리하며 보관 API에 해당 행은 없었다. 체인·콤보 조작은 추가 입력 조작으로 표시하고, 기본 MP를 타격 수만큼 차감하지 않는다. 실제 시전과 추가 입력의 차감 주기는 실측이 필요하다.

미장착 또는 장착 미확인 스킬이 자동 계획을 차단하지 않는다. 사용자 지정 계획에는 직접 입력한 스킬을 사용한다. 포함한 상태 스킬이 불명일 때도 사용자 입력 비용은 조건부 분석에 쓸 수 있으며, 그 입력으로 일반 마나 감소나 용광로 적용 여부까지 판단하지 않는다. 장착 추정 스킬이 일부 빠진 경우 시뮬레이션의 범위가 제한되며 전체 마나 지속력과 피해 손실률은 보류한다. 1레벨 유틸·게이지·상태 전환 및 게임에만 있는 실제 시전은 별도 확인 대상이다.

마리포사의 원문은 `정령의 구슬 1 소모`를 표시한다. 시간 엔진에만 있던 판정을 공통 파서로 올렸다. 시간 엔진의 비용은 이미 0이었으며 이론 엔진은 기존의 `UNKNOWN`을 명시 비마나로 고쳤다. 마리포사 자체에 용광로 피해나 추가 소모를 부과하지 않는다. 다른 MP 스킬에 용광로를 적용하는 조합이 이론 비교에 다시 들어왔으며, 금단의 주문 등 마나 대상 효과도 동일 플래그를 읽는다.

## 서포터·사용자 입력

| 서포터 | 자동 표시할 공식 효과 | 이론 및 사용자 입력 |
|---|---|---|
| 바드 | 천상의 연주 기본 30초, 8초 회복 속도 +40% | 계산 쿨 기반 가동률, 효과 중 실측 틱 우선 |
| 홀리나이트 | 천상의 축복(완전한 축복) 기본 30초, 8초 회복 속도 +50% | 동일한 수신 시간 기반 경로 |

| 도화가 | 해우물 기본 30초, Lv.7 22%/Lv.14 25% 즉시, 선택 트라이포드 +12% | 지속 가동률 대신 분당 수신 횟수. 최대 MP 비례 가정은 실측 회복량으로 대체 |

이론을 명시적으로 켰을 때 기존 스킬 쿨타임 계산으로 기본 쿨·신속·보석·고정/비례 트라이포드 쿨감을 계산한다. 직접 시전 간격은 이론 반복 간격을 대체한다. 실제 수신 목록, 또는 지속형의 사용자 가동률이 있으면 그 타이밍으로 계산한다. 30초 기본 스킬에 트라이포드 -5초, -10%, 신속 쿨감 25%, 보석 쿨감 20% 예시에서 13.5초 및 8초 효과 이론 가동률 59.26%를 독립 검산했다. 계산 간격마다 조우 시점부터 회복한다는 표시는 가정이다. [서포터 툴팁 목록](mana-verification-2.md#지원-및-자체-회복) · [한국 공식 밸런스 공지](https://lostark.game.onstove.com/News/Notice/Views/13598)

동시 회복 130·150 MP 구간에서 엔진이 150만 적용하는 것을 테스트에서 확인했다. 이는 엔진 규칙이다. 같은/서로 다른 효과의 게임 내 중첩과 틱 위상은 UNKNOWN이므로 각 효과를 무조건 합산하지 않는다. 실제로 겹친 구간을 실측했다면 총 회복량을 버프 구간에 지정할 수 있다.

기본 화면은 최대 마나, 계획 소모·예정 회복·순수지, 지속력, 서포터·음식을 표시한다. 상세는 수신 시간·회복 틱·시전 계획·A/B/C 비용·그래프에 둔다. 캐릭터별 입력은 열린 브라우저 세션의 작업 공간에 유지한다. 장비 변경 후 이전 최대 MP·회복 측정값을 자동 재사용할 수 있어 영구 로컬 저장은 채택하지 않았다.

## 실측 항목과 재현

Lv.70 최대 MP 및 레벨별 차이, 전투/비전투 기본 틱, 액세서리·각인·아크 패시브의 적용 순서, 음식/만찬 지속·중첩, 심판의 실제 쿨·발동률, 상태·각성 기술의 MP 및 용광로 판정, 용광로 A/B/C, 지원 효과의 수신 거리·실효 가동률은 별도 게임 실측이 필요하다. 같은 캐릭터에서 회복 틱 사이의 소비를 먼저 기록하고 집중·트라이포드·진화 감소를 하나씩 넣은 뒤 각각의 용광로 전후 차이를 사용한다. 회복 중첩은 두 효과의 개별 틱과 동시 틱을 비교한다.
