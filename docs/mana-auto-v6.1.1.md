# v6.1.1 자동 마나 환경과 진화 TOP5

복구 태그 `backup/pre-v611-auto-mana`는 v6.1.0 기준 커밋 `70da2ed`를 가리킨다.

## 추천 화면과 데이터

닉네임 검색 후 서포터를 고르면 추천을 즉시 다시 계산한다. 수동 마나 환경, 음식, 회복량·가동률·시각, 전투 시간과 각 스킬 사용 설정은 고급 마나 설정에 있다. 수동 조건을 사용 중이면 입력 변경 즉시 순위를 갱신한다.

| 결과 | 적용 조건 |
| --- | --- |
| 검증된 프로필 마나 반영 순위 | 현재 패치와 캐릭터 서명이 일치하고 피해 지분을 스킬에 연결할 수 있으며, 선택한 서포터의 적용 시각과 실측 효과를 확인한 경우. 등록된 실전 프로필은 현재 0개다. |
| 가정 기반 자동 TOP5 | 최대 마나를 확인하고 장착 추정 스킬의 기본 비용과 쿨을 읽었으며, 기존 전투분석 표본의 피해 지분을 모두 개별 스킬에 매핑한 경우. 보석 균등 지분과 범주 지분의 균등 배분을 이 순위에 사용하지 않는다. |
| 이론상 TOP5 | 핵심 데이터가 부족해도 기존 기대 피해 순위를 표시한다. 가상 시전 일정을 만들 수 있는 경우 추천 카드에서 지연 없이 일정을 소화하는 데 필요한 최소 최대 마나를 확인할 수 있다. |
| 수동 조건 마나 반영 순위 | 고급 설정의 사용 간격, 회복과 용량에 따른 결과다. 서포터 가동률 등 시점을 추정한 입력은 가정 기반 비교에 표시한다. |

현재 레벨 스킬 툴팁, 집중 룬이나 선택 트라이포드의 단일 수치형 소모 효과, 신속·보석·트라이포드·해석 가능한 그리드 쿨 감소를 기존 파서와 모델에서 읽는다. 장착 후보는 포인트·트라이포드·룬으로 파악하므로 포인트와 룬 없이 사용하는 1레벨 유틸 등은 빠질 수 있다. 공식 응답에서 확인되지 않은 최대 마나는 생성하지 않는다. 비용이나 쿨이 미확인인 스킬이 있으면 가상 운용을 만들지 않는다. 특수 자원·변신·연동 쿨과 마나 지연은 검증 자료가 필요한 상태다. 로아인벤 연동은 기존 방식과 동일하다. [공식 API 변경 이력](https://developer-lostark.game.onstove.com/changelog) · [기존 데이터 경로와 서포터 공식 툴팁](mana-environment-v6.1.0.md)

## 가상 운용 조건

- 기본 전투 시간은 기존 계산 창을 사용한다. 가득 찬 상태에서 시작해 조우 1초 후부터 매초 최대 마나의 4.44%를 회복한다고 가정했다. 이 비율은 2024년 홀리나이트 관찰값에서 가져왔다. 관찰 당시의 최대 마나는 가져오지 않았다. 음식, 추가 회복과 조건부 쿨 감소는 가상 운용에 포함하지 않는다. [공개 관찰 자료](https://www.inven.co.kr/board/lostark/4821/100754)
- 추정 스킬을 목록 순서로 조우 시점에 등록하고 각 쿨이 돌아올 때 사용한다. 시전 시간, 보스 패턴, 직업 자원과 실제 로테이션은 별도 검증이 필요하다. 대안 시나리오에서는 첫 사용을 가장 짧은 쿨 안에 등간격으로 분산하고 순서를 뒤집으며, 마나 소모 감소를 개별 곱에서 합산으로 바꾼다. 화면에서 두 시나리오의 TOP5 일치 여부나 필요 마나 차이를 확인할 수 있다.
- 회복 효과는 조우 시점과 이후 30초마다 받은 것으로 가정한다. 바드와 홀리나이트·발키리는 8초 구간에만 회복량을 변경한다. 바드는 +40%, 홀리나이트·발키리는 +50%다. 도화가는 적용 시 대상의 최대 마나 25%를 즉시 회복한다고 가정한다. 실제 효과 적용률과 틱 방식은 미검증이다. [서포터별 공식 툴팁 표본](mana-environment-v6.1.0.md#서포터-회복-툴팁) · [11월 18일 공식 패치](https://lostark.game.onstove.com/News/Notice/Views/13598)
- 최소 최대 마나는 연속된 각 시전 구간에서 고정 소모·최대 마나 비례 소모와 사이의 회복을 동시에 만족하는 가장 작은 값이다. 같은 시각에는 회복을 먼저 적용하며 최대 마나를 초과하는 회복은 이후 소비에 이월되지 않는다. 최소량보다 ±1 MP인 시나리오를 기존 지연 엔진으로 교차 확인했다.
- 부족한 경우 기존 엔진으로 스킬 시전을 지연하고, 줄어든 사용 횟수가 해당 스킬의 기대 피해에 반영된다. 지연 없는 후보를 우선하고 그 안에서 마나 반영 기대 피해로 정렬한다. 뭉툭한 가시의 피해와 마나 용광로의 피해·추가 소모 공식은 기존 값을 사용한다. 마나 모듈을 골드 효율 계산 입력에 연결하지 않는다.

## 회귀 표본의 TOP5 비교

두 스킬, 최대 마나 665, 60초로 고정한 합성 테스트다. 후보 피해 배율은 테스트용이며, 아래 순위는 실제 직업의 레이드 순위로 해석할 수 없다. v6.1.0 수동 입력 전의 이론 순서와 v6.1.1 이론 순서는 같다.

| 순위 | 두 버전 이론 | v6.1.1 자동 가정 · 서포터 없음 | v6.1.1 자동 가정 · 바드·도화가·홀리나이트·발키리 |
| ---: | --- | --- | --- |
| 1 | 뭉툭한 가시 | 가시·금단 | 뭉툭한 가시 |
| 2 | 마나 용광로 | 가시·끝없는 마나 | 가시·금단 |
| 3 | 가시·금단 | 뭉툭한 가시 | 가시·끝없는 마나 |
| 4 | 가시·끝없는 마나 | 용광로·금단 | 용광로·금단 |
| 5 | 용광로·금단 | 일반 | 일반 |

기본 후보가 일정대로 시전하는 데 필요한 최소 최대 마나는 서포터 없음 689, 바드 640, 도화가 643, 홀리나이트·발키리 631이다. 최소 마나는 정수로 올림했다. 대안 가정에서 서포터 없이 계산하면 뭉툭한 가시는 3위에서 4위로 이동한다. 최대 마나를 충분히 확보한 테스트에서는 이론과 자동 순위가 일치한다.

PC와 모바일 브라우저 테스트에서는 모의 캐릭터 API 응답으로 사이트의 전체 조합 탐색을 실행했다. 서포터 없이 가장 높은 자동 추천은 끝없는 마나 1·금단의 주문 1·최적화 훈련 1이었다. 도화가를 선택하자 이론 1위였던 끝없는 마나 2·최적화 훈련 1이 자동 1위로 올라왔다. 두 조합 모두 달인·분쇄·입식 타격가 2였으며, 각 조건의 1위 마나 반영 배율은 2.2541과 2.2786이었다. 두 뷰포트의 TOP5가 일치했다.
